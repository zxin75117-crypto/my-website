# 设计系统

个人网站 `index.html` 的视觉规则。单文件、自包含、无构建步骤——所有令牌写在 `:root` 里，改这个文件就是改设计系统。

**Why 这份文件存在**：站点的样式分散在 500 多行 CSS 里，改一个颜色容易带出五个不一致的近似色。这里只记"已经定下来的值"和"为什么定成这样"，不记实现细节。

---

## 色彩

| 令牌 | 值 | 用途 |
|---|---|---|
| `--accent` | `#ffb35c` | 唯一强调色。圆点、选中态、进度条、下载按钮 |
| `--ink` | `#fff4f2` | 正文、标题 |
| `--ink-2` | `#f0cfcc` | 次级文字、说明 |
| `--on-ink` | `#2a0509` | 铺在 `--ink` 上的反色文字 |
| `--panel` | `rgba(28,6,12,.52)` | 面板底色 |
| `--panel-hi` | `rgba(70,16,28,.82)` | 悬停/选中面板 |
| `--line` | `rgba(255,225,220,.16)` | 分隔线与描边 |

背景不是固定色：`--sky-top / --sky-mid / --sky-bot` 由 JS 按当前时间在 11 个关键帧之间插值，全天最亮是正午的 `#9c1429`，最暗是凌晨的 `#070103`。

**对比度实测**（都过 AA）：正文 `--ink` 在面板上 13.0:1，次级 `--ink-2` 在面板上 9.7:1、在正午天空上 5.7:1，`--on-ink` 在 `--accent` 上 9.5:1。天空最亮的一档是 17:30 的 `#cc5028`，裸色上 `--ink-2` 只有 3.06:1——但正文永远叠在 `.vignette` 之上，压暗后实测 ≥5.5:1；`--vignette` 的收尾从 .6 加到 .7 就是为了留这条余量，不要再调亮。**不要给 `--ink-2` 再加 opacity**——书架的提示文字曾用 `opacity:.8` 掉到 3.5:1，是这轮修掉的唯一一处对比度缺陷。

## 间距

`--s1:4 --s2:8 --s3:12 --s4:16 --s5:24 --s6:32 --s7:48 --s8:64 --s9:96`（px）。

面板内边距统一 `--pad: clamp(20px,2.6vw,32px)`：经历面板、音乐播放器、书架、书籍信息卡都用它，四个模块的内边距从此一致。

新代码只从这里取值。区块内边距 `clamp(72px,9vw,104px) 0 var(--s7)`，标题区下边距 `--s7`——永远是"标题上方空间大于下方"。

## 圆角

`--r-xs:10 --r-sm:14 --r-md:20 --r-lg:26 --r-xl:32`，胶囊一律 `999px`。

历史遗留的 22/24/26/28/30 混用已经收敛到这几档。照片卡片 `--r-md`，面板 `--r-lg`，书架 `--r-xl`，书本封面保留自己的 3px/8px（那是书的形状，不是组件）。

## 玻璃

`--glass: blur(18px) saturate(1.35)`，**只有一档**。同一屏内不出现两种模糊强度。

嵌套警告：搜索框、标签这类小控件不要加 `backdrop-filter`，它们本来就落在面板里，二次模糊只会让层级糊掉。

## 动效

| 令牌 | 值 | 用途 |
|---|---|---|
| `--d1` | 120ms | 按下反馈 |
| `--d2` | 220ms | 悬停、颜色、位移 |
| `--d3` | 360ms | 面板展开、切换 |
| `--d4` | 640ms | 首屏入场、图片缩放 |
| `--ease` | `cubic-bezier(.22,1,.36,1)` | 推进 |
| `--ease-soft` | `cubic-bezier(.4,0,.2,1)` | 收束 |

规则：所有可点元素必须有 `:active` 压缩反馈（`scale(.98)` + `--d1`）；`prefers-reduced-motion` 下全局动画时长压到 0.001s，图带改为可横向滚动。

## 排版

字体栈：`--sans`（PingFang SC 系）、`--serif`（Iowan/Palatino/Georgia）。

**字阶只有七档**（`--fs-2xs .76 / --fs-xs .85 / --fs-sm .95 / --fs-md 1.05 / --fs-lg 1.35 / --fs-lead clamp(1.12–1.45) / --fs-xl clamp(1.4–1.95) / --fs-2xl clamp(1.85–2.7)`）。此前全站有 36 个不同字号，0.70–1.05rem 之间挤了 16 档，相邻只差 0.02–0.03rem，肉眼分不出。新代码只能引用这七档；正文基准 16px、首屏姓名 `calc(var(--av)*.98)`、经历大年份 `clamp(4rem,9vw,7rem)` 是三处例外。

三条硬规则：

1. **中文不用 `font-style:italic`**。中文字体没有真斜体，浏览器会合成一个倾斜，这是廉价感最直接的来源。衬线斜体只留给**纯数字**——时钟、年份、曲目时长、页码。这些斜体数字是本站最有辨识度的细节，别动。
2. **中文标题字距不小于 `-.02em`**。负字距是给拉丁字母收紧用的，中文汉字之间本来就有字面空隙，收到 `-.05em` 会挤在一起。
3. 中英混排的行高、字重要一起定，不要让中文走 800、拉丁走 500。

## 组件

**首屏线条**：`#heroLines` 画双螺旋——两根骨架 + 每圈约 13 组碱基对（两截、中间留缝），按深度分桶着色（越靠前越亮），断裂时分成 7 段小幅飘散再合拢。桌面 7.5 圈、手机 5 圈，半径 = 螺距 × 0.4。

**首屏**：`.hero` 定义 `--av: clamp(88px,11vw,140px)`，头像宽度等于 `--av`，名字字号等于 `calc(var(--av)*.98)`。两者永远等高，改首屏比例只动 `--av` 一个值。

**标题区**：只有 `<h2>`，没有说明段落。设计上刻意不给"点击这里查看"这类提示——交互应该被看懂的，不是被解释的。

**照片图带**（所有分类）：每排反向滚动，每排重复一份自己，位移 50% 实现无缝循环。照片 ≥6 张分两排、不足 6 张单排；每排按张数换算时长，视觉速度保持一致。悬停或键盘聚焦时暂停，移出视口由 IntersectionObserver 暂停。

**照片信息**：标题与渐变遮罩默认透明，悬停或聚焦时淡入；`@media (hover:none)` 下常驻显示，触摸屏没有悬停。用 `opacity` 而不是 `display`，读屏仍能拿到标题。

**书柜**：3D 弧形卡带。书排在一段朝观众凸起的圆弧上——中间的离得最远、两端的最近，透视下就是「两头长、中间短」。可见半角 84°（30 本书时约 15 本同屏）、透视 1300px、旋转上限 ±75°、两侧各留 62px 给翻页按钮。卡片宽度按「角度间距 × 1.15」算，相邻两本叠压约 13%，拼成一条连续的带子而不是一排独立的卡片。半径先按模块宽度推算，再迭代收小以抵消「透视会把外侧卡片继续外推」的那部分，否则翻页按钮会压到书上。默认常转，没有暂停开关；拖动 `gain = 0.26 + min(0.34, |dx|*0.01)`，松手 `0.972/frame` 滑行。

**首屏 DNA**：canvas 画的 3D 双螺旋。每帧按 `s = sin θ × R` 把进深同时用作轴线剪切和透视系数（`k = CAM/(CAM ∓ s)`，`CAM = 3.2R`），所以近侧的螺旋更宽更亮、远侧更窄更暗；按深度切 8 个桶分批描边，近桶更粗更不透明，碱基对先画、骨架后压，才有包住的纵深。舞台高度由 `measure()` 按透视投影算出（前排封面会被放大到 1.3 倍），**不要写死高度**——写死的那一版在 700–1200px 宽度上会把封面压到下面的控制条上。

## 维护提示

- **媒体查询必须写在基础规则之后**。`@media` 不提升优先级，写在前面会被后面的基础规则覆盖——改成"改了但没生效"时先查这个。
- **`impeccable detect` 的残留项是有意为之，不要改**：`radial-halo` 是黑胶唱片的中心标签，`repeating-stripes` 是书页截面的纹理，`broken-image` 是灯箱里尚未赋值的 `<img id="lbImg">`，`dark-glow` 是站名旁边那颗暖色圆点。
- 改完至少跑一次语法检查：抽出 `<script>` 用 `node --check`，再截图看渲染。
- 站点根目录就是发布目录。**不要往根目录放草稿**——任何文件都会被公网访问到。这份文档放在 `_design/`，GitHub Pages 的 Jekyll 默认忽略下划线开头的目录；如果以后迁到普通静态服务器（整目录上传），记得把 `_design/` 排除。
